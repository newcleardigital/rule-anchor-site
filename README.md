# Landing page

Static page served at https://rule-anchor.newcleardigital.com by GitHub Pages from the `main` branch. Source of truth: `site/` in newcleardigital/anchor-development.

- `index.html`: the whole page. `CALL_URL` at the bottom sets where "Book a call" goes (empty = email).
- `fonts/`: self-hosted (SIL Open Font License), so the page loads nothing from other servers.
- `CNAME`: the custom domain.
